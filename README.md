# PolyHitbox

[![Modrinth downloads](https://img.shields.io/modrinth/dt/Mptc0jo6?style=flat&logo=modrinth&label=Modrinth&color=1bd96a)](https://modrinth.com/mod/hitbox)
[![CurseForge downloads](https://img.shields.io/curseforge/dt/1148007?style=flat&logo=curseforge&label=CurseForge&color=f16436)](https://www.curseforge.com/minecraft/mc-mods/polyhitbox)

PolyHitbox replaces Minecraft's hitboxes with ones you can style, down to which entities get one.

![Styled hitboxes](.github/images/hitboxes.gif)

### What you can change

- Toggle the outline, filled sides, eye height ring and view ray separately
- Custom color and line thickness for each of them
- Solid or dashed lines
- A different color for the entity you are looking at
- A different color while an entity is in i-frames, so you can see when it can be hit again
- Draw hitboxes on top of their entity

![Picking an outline color](.github/images/color.gif)

### When they show

- Always, only for the entity under your crosshair, or toggled with a keybind
- Hidden together with the HUD when you press F1
- Hide the hitboxes of arrows stuck in blocks

### Per entity type

All of the above can be set differently for players, yourself, mobs, monsters, projectiles, arrows, fireballs, wither skulls, item frames, armor stands, items and XP orbs.

![Entity tabs](.github/images/entity-tabs.gif)

On 1.8.9, "Accurate Hitboxes" draws each hitbox at the size attacks register against.

## Compatibility

PolyHitbox doesn't work together with Combat Hitboxes.

## Supported versions

- Minecraft 1.8.9 on Ornithe.
- Minecraft 1.21.1-26.3 on Fabric.

PolyHitbox needs [OneConfig](https://modrinth.com/mod/oneconfig) and Fabric Language Kotlin.
